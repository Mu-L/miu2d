# Miu2D 武侠图标

使用内置 imagegen 生成，原始图片为 `miu2d-wuxia-source.png`。采用墨黑背景、金色剑气与古剑；不含文字，便于在标签页显示。使用 Sharp 缩放输出 PNG 和 ICO，maskable 版本增加安全留白。发布文件带 `wuxia-v1` 版本，避开 CDN 和 PWA 中旧图标的长期缓存。

用于网站 favicon、首页导航、页脚、账号页面和 PWA 更新提示。各游戏自己设置的安装图标仍由游戏 API 提供。
